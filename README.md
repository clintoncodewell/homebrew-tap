# clintoncodewell/homebrew-tap

Homebrew tap for Clinton Cunningham's lightweight macOS menu bar apps.

## RamGuard — RAM / CPU / disk / network monitor with process killing

```bash
brew install clintoncodewell/tap/ramguard
```

[Repo](https://github.com/clintoncodewell/ramguard)

## Cat Eye — GitHub Actions & PR status

```bash
brew install clintoncodewell/tap/cat-eye
```

[Repo](https://github.com/clintoncodewell/cat-eye)

---

Both build from source with `swiftc` (no notarization / Gatekeeper prompts), are MIT licensed, and run as menu bar apps. Update with `brew upgrade`, remove with `brew uninstall`.
